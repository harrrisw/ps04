## Scene 7

The main architectural tradeoff is inspectability versus operational complexity. Separate Bash interfaces make each stage easy to inspect and replay; Python handles parsing, model calls, and storage. Immutable evidence preserves provenance, but a fresh clone must reconstruct the ignored SQLite index. Media caching reduces repeated downloads and transcription, while silent source edits may require an explicit refresh. Actual model dollar cost remains unknown where the provider did not report it.
